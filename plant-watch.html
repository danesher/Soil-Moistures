This is a live demo

Readings above are simulated so you can see how the dashboard behaves. Wire it to a real pot and the same layout works with actual sensor data.

  1. 1 Connect a capacitive soil moisture sensor to an ESP32 (it has WiFi built in, so no separate bridge device is needed).
  2. 2 The ESP32 reads moisture every few minutes and pushes the value to a small cloud database (Firebase's free tier is enough for this).
  3. 3 This page reads from that same database instead of the simulator, so the numbers you see are the real pot.
  4. 4 When moisture drops below your threshold, the ESP32 can send a push notification to your phone via a service like Pushover.
Plant Watch — a demo dashboard. Swap the simulator for your sensor feed when your hardware is ready.
